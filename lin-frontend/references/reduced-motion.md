# LIN｜一般與減少動態雙模式

適用 GSAP／ScrollTrigger、Lenis、AOS、輪播及其他進場／捲動效果。品牌、內容與功能必須完整，動畫是呈現方式；兩種模式可以有不同閱讀布局，但不能缺資訊或降低正式設計完成度。尺寸與 RWD 維持本案範圍；同一桌機尺寸驗收兩種動態模式，不等於另外新增手機階段。

## 設計與預設取捨

- 預設尊重 `prefers-reduced-motion`，不為追求每台電腦動畫相同而忽略作業系統偏好。偵測到 reduce 是預期切換，並不代表套件或工程師接入故障；仍須檢查替代布局是否完整。
- 一般模式保留已確認品牌演出；減少動態模式保留品牌圖像、排版層級、故事、文字、圖片、CTA 與全部必要功能，減少非必要的位移、縮放、旋轉與持續動態。不將全站操作關閉，也不把 reduced motion 等同低效能裝置。
- 製作前為每個複雜動態區塊定義「一般模式如何演出／減少動態模式如何完整閱讀」。靜態構圖應成立，不讓內容必須等動畫才出現；同一份內容 DOM 優先適配兩模式，不複製兩份主標題造成違反單一 h1 內部規定。
- 僅在使用者核准案件需要時，才加入網站自己的「啟用完整動畫」選項。預設仍尊重系統，訪客主動選擇後才切換，不自動強制啟用、不改訪客的 OS 設定，也不因本規範就每案新增設定 UI。

## 效果替代方式

| 一般模式效果 | 減少動態模式 |
|---|---|
| GSAP scrub，動畫跟隨捲動進度 | 取消捲動連動，靜態展示關鍵資訊；多場景逐一可閱讀，不只留下最後一幕。 |
| GSAP pin，固定舞台依序展示 | 解除固定及額外捲動留白，改成正常閱讀順序，內容高度依實際資訊。 |
| 捲動帶動橫向展示 | 改為直向清單、網格或完整可讀的靜態排列，不要求捲動動畫才能到下一項。 |
| 大幅視差、縮放、旋轉 | 保留有品牌目的的構圖，停止非必要位移；原本重疊的場景改成各自可閱讀的位置。 |
| 拆字、文字／圖片進場 | 直接顯示完整內容；恢復原始文字結構，不留下透明、錯位或只顯示部分字的狀態。 |
| Lenis／平滑捲動／回頂部 | 沿用原生捲動，必要操作保留，不強制平滑動畫。 |
| 選單、輪播、燈箱、按鈕 | 開關、切換、前後張與鍵盤等功能保留，減少轉場；非必要自動播放依案件設定停止，仍可手動操作。 |

例如「固定舞台依序介紹三個產品」，減少動態版應讓三個產品及各自說明完整排列；不得用 timeline.progress(1) 當作通用解法，使前兩項資訊消失。

## 實作與模式切換

- 沿用案件 GSAP 版本與初始化。支援時用 `gsap.matchMedia()` 管理 `no-preference`／`reduce` 兩分支，正常動畫及 ScrollTrigger 在對應分支建立；條件改變時讓 GSAP 還原該次建立的動畫及 triggers。元件移除時使用所屬 matchMedia 的 revert，不能在 cleanup 裡遞迴呼叫自身 revert。
- MatchMedia 不會自動處理全部自訂邏輯；自行管理的事件、拆字、CSS class、Lenis、RAF／ticker 及其他非 GSAP 實例，須依各自生命週期清理與還原。延後建立的 GSAP 動畫也須納入所屬 context 或明確管理，不能以為整份 JS 都自動受追蹤。
- 切換偏好後先清理舊模式，再套對應布局與必要初始化；處理再次開啟完整模式，避免同時存在兩套 Lenis、ScrollTrigger、事件或 RAF。缺套件時保持完整原生閱讀，不靠固定延遲猜載入時機。
- 基本內容預設可見；動畫分支才施加起始隱藏狀態。減少動態 CSS／JS 檢查並還原本區自有的 opacity、visibility、transform、clip／遮罩、absolute 疊層、固定高度與 pin 留白，布局穩定後才刷新必要量測。不能只 early return、把 duration 設 0 或全域 transition 清零就宣稱完成。
- 僅清理本區自己建立的動畫、樣式與 spacer；不使用全域 killAll、清除全部 inline style 或刪掉其他區塊的 pin。CSS media query、JS 偏好判斷與已核准的 UI 選項須使用一致模式，不讓 JS 播放但 CSS 把內容藏掉。

## 雙模式驗收與交接

1. 一般模式驗收已確認的完整動畫、正反向捲動、pin 交接、內容與 CTA；記錄 prefers-reduced-motion 的實際值，不只假設這台電腦會播放。
2. 減少動態模式驗收全部文字／圖片／場景、正常閱讀順序、導覽及互動，檢查空白、疊層、遮擋、缺內容、橫向捲軸與 console；即使動畫停用，仍須正式視覺完成度。
3. 測試頁面初次載入及開啟後切換模式，確認舊實例／pin 留白解除、可再次恢復一般模式、沒有重複綁定。需要訪客 UI 選項的案件另驗該選項；尚未核准不新增。
4. 兩種模式的完成／待驗分開記錄，回填 `工程師交接說明.md` 的各區替代方式、偵測／清理位置與重現步驟。沒有實作或實看不能宣稱通過。

要看完整演出，驗收人員可自行開啟 Windows 11「設定 → 協助工具 → 視覺效果 → 動畫效果」、Windows 10「設定 → 輕鬆存取 → 顯示器 → 在 Windows 中顯示動畫」，再重新整理；也可使用瀏覽器開發工具模擬偏好。這是驗收操作，不要求一般訪客改系統設定才能閱讀網站。

依據：[MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)、[GSAP matchMedia](https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/)。依本案實際版本核對 API，不因文件提到套件就自行安裝或升級。
