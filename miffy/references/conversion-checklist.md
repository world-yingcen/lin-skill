# Miffy｜轉換與驗收檢查

開始轉換時讀本檔；只驗本案涉及的功能與已授權尺寸。以下是檢查項目，不是平台 schema 或 CLI 定義。

內頁另外依 [工程師內頁匯入規範](designer-guide-rules.md) 檢查 main／wrapper、`data-trans`、正式 vendor 版本、`data-repeater`、畫布與前台初始化差異，以及 `faq001` 的完整結構。

## 來源與轉換對應

| 項目 | 要確認的內容 |
|---|---|
| 頁面 | 真正的 HTML 入口、首頁／內頁／分類／文章類型、轉換範圍 |
| 共用區塊 | Header／Footer／Cookie／回頂部由誰提供，匯入邊界及正式接入方式 |
| 樣式 | SCSS → CSS → 頁面的對應、共用／單頁隔離、字型、載入順序 |
| 互動 | 共用／單頁 JS、套件版本、依賴、初始化與移除時機、畫布是否執行 |
| 內容編輯 | 平台資料或頁面清單、欄位、增刪排序需求、可用的正式標記 |
| 素材 | 原始路徑、輸出檔名、匯入後路徑、缺檔、重複檔名與相對路徑 |
| 工程工具 | 實際工具版本、支援模式、必要命令、輸入／輸出、驗證與打包格式 |

從實際檔案自動整理，不要求設計師手填。不能只看範本名稱便推定資料綁定或可編輯介面。

## 轉換包與資源

- 輸出只含契約要求的內容。排除 `.DS_Store`、憑證、環境設定、Git 資料與不屬交付的工程工具；不套用未核對的 ZIP 結構。
- 工具驗證成功後，實際檢查包內檔案、資料結構與素材引用；核對必要 ID／引用一致、多實例不衝突、沒有他案資料及誤帶預覽元件。
- 本案格式若不攜帶 CSS／JS，確認另外交付的資源完整，說明共用與單頁各自的接入位置。移除預覽用 script 不等於捨棄該功能。
- 保留可重現的來源、工具版本、命令及報告；不要只手改輸出 JSON 修掉當下症狀。

## 視覺與操作

- 以同一份內容及相同 CSS viewport 比較來源與可用的轉換預覽／前台：容器、留白、字級、換行、圖片裁切、層級、固定元素與動畫交接。
- 檢查本案原有 desktop／tablet／mobile，不新增原本未要求的 RWD。受影響的寬度斷點 B 檢查 B−1px、B、B＋1px；其他單位記錄換算環境，小數或窄區間補相鄰尺寸。
- 測導覽、輪播、FAQ、頁籤、表單、Cookie、政策連結及回頂部等實際存在的功能。正式表單送出依授權，前端模擬不顯示假的寄送成功。
- 測正反向捲動、重載、resize、鍵盤焦點及減少動態；檢查 console、資源載入與重複初始化。共用資源改動時檢查首頁與受影響內頁。

## 後台編輯與發布後前台

有可用且已授權的測試環境才操作；優先使用測試頁或副本，不用正式內容做無法還原的測試。

1. 修改文字與圖片，測長短文案及比例變化；逐筆清單另測新增、刪除、排序與完整項目欄位。
2. 儲存後重新開啟，確認內容及標記仍在、沒有存入動畫副本或執行中數值。
3. 在已授權發布的環境查看前台，確認最新內容、素材正式路徑、樣式、互動與動畫終值一致。
4. 確認輪播張數、頁籤對應、FAQ 及多實例操作跟隨變更，不靠舊快取或固定 JS 內容。

缺後台存取時，本機內容變更模擬仍可執行，但後台編輯／儲存／發布列「待驗證」。匯入成功不等於上述功能通過；發布也不能代替前台操作驗收。
