先完整讀取 [Lin-EVO 工作指南](resources/Lin-EVO/GUIDE.md)，再按任務讀取所需參考。
使用繁體中文與台灣用語，保留案件已確認的設計、內容、互動與 RWD 範圍。

## 上傳環境的優先規則

本節優先於工作指南中僅適用本機的安裝與更新操作，其餘規範維持有效。

- 本包是來源快照，不執行本機 install.py、安裝紀錄查找、Plugin 安裝或 Skill 來源 Git 更新。
  更新規範須重新打包、由使用者上傳並啟用；不能把來源快照說成每輪已查遠端最新版。
- 只讀使用者提供或工具已授權且實際可存取的案件資料；不能假設可讀本機絕對路徑、
  localhost、Google Drive 同步資料夾、公司內網或登入中的後台。缺資料列具體項目。
- 案件 Git 依可用工具及授權處理：每輪先檢查 repo、分支、工作中修改與 upstream，
  fetch 並比較；乾淨且僅落後才快轉。缺工具提供操作步驟，不宣稱已同步。
- 尚未轉 EVO 的 Git 案件換電腦前，核對目標與範圍後 commit 並 push 成功，另一台先讀交接再續作。
  已成功轉 EVO 的案件改至後台，原靜態 Git 只供查閱，不再修改或 push。ZIP／預檢通過不等於已匯入。
- 本包不內附工程師套件；整站 HTML 任務須先讀取另行啟用的 Miffy-EVO 內附 evomni-html，依實際可用工具定位，不猜另一個上傳包的檔案路徑。Lin 與 Miffy 在同一案件使用同一套件及版本。缺少 Miffy 或套件時列出缺口，不編造契約。
- Lin-EVO 與 Miffy-EVO 是分別啟用的 Skill；需要另一個 Skill 時確認本對話可用，
  不猜另一包路徑、不假裝已讀取。缺依賴時完成不受影響的工作並明列缺口。
- 有程式執行能力才編譯、執行檢查器與打包；有瀏覽器才實看、實測。
  工具不可用時依工程師替代檢核流程交後台預檢，不偽造 evomni-check.json 或驗收結果。
- 實際上傳、匯入及發布依指定站台與授權；本機檢查、後台編輯儲存與發布後前台分開記錄。
  保留工程師套件原檔，不為通過檢查而修改契約或降低檢查。
- 圖片轉檔與壓縮依案件既有分工，不因打包擅自處理。Skill、示範網站與來源紀錄不放入客戶網站 ZIP。

來源版本、建置時間與逐檔 SHA-256 見 SOURCE.json。本包已完成打包檢查，不代表已在 Claude 上傳或啟用。
