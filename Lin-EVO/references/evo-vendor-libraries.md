# EVO｜系統第三方套件載入契約

依使用者於 2026-11-06 轉達的最新工程師說明更新，取代 2026-10-13 的部署預告。適用 EVO 系統頁面與待匯入的版型；不替其他框架改載入方式，也不因套件可用就每案全部啟用。

## 已開放套件與版本核對

**工程師已確認 Lenis 1.3.26 放入 EVO 系統並正式開放。** AI 切版需要平滑捲動時可使用 `data-vendor="lenis"`，不再以「尚待系統更新」阻擋實作；不因開放就每案自動加入。既有站若實際版本不同或發布後載入失敗，記錄該站差異並保留原生捲動，不自行補 CDN 或另一份套件。

查本案 `evomni-page-composer` 套件內：

- `.claude/skills/page-composer/SKILL.md`「鐵律 11」。
- `knowledge/designer-markup-guide.md`「四之二、要用到函式庫時」。

以上為套件相對位置，不當成全域安裝路徑。找不到或本機文件尚未更新時如實標示，以本次工程師說明作契約紀錄，不能宣稱已查到新版指南。使用者本次轉達的已開放說明優先於舊文件；實際站台載入與操作仍需於發布前台驗證。

## 平台載入方式

站台的套件由系統提供本機檔案，不走 CDN。**AI 不自行加入第三方套件的 `<script>`／`<link>` 引用；版型自己的 JS／CSS 依既有資源管線接入。**

| 套件 | 工程師指定版本 | 平台啟用方式 |
|---|---|---|
| Swiper | 12.2.0 | 元素宣告 `data-vendor="swiper"` |
| GLightbox | 3.3.1 | 元素宣告 `data-vendor="glightbox"` |
| Lenis | 1.3.26 | 已開放；元素宣告 `data-vendor="lenis"` |
| GSAP，含 ScrollTrigger | 3.12.7 | 由編輯器工具列開啟，**不寫 data-vendor** |
| AOS | 2.3.1 | 由編輯器工具列開啟，**不寫 data-vendor** |

```html
<!-- 需要平滑捲動時宣告；初始化另寫在版型 JS -->
<main data-vendor="lenis">…</main>

<!-- 多個 vendor 以空白分隔，不用逗號 -->
<div data-vendor="swiper glightbox">…</div>
```

只宣告需要的套件；確認已有相同宣告或啟用機制，不重複建立載入器。名稱須精確使用上表小寫值，錯字如 `swipper` 不會載入，DevTools console 會有警告。既有案件版本不同時先依實際契約處理，不能強制升級或混用不同版本的 JS／CSS。

## 載入與初始化分開

- `data-vendor` 只負責載入檔案，不會自動建立 Swiper、GLightbox 或 Lenis 實例。初始化寫在版型自己的 JS，或本案既有全站共用入口，依指定版本官方文件實作。工程師範例為 `new Swiper(...)`、`new Lenis({ autoRaf: true })`；這些不是平台已自動初始化的證據。
- 本案需要全站 Lenis 時，依 [JS 分工](javascript-rules.md) 在既有全站入口集中管理單一實例，不逐區建立。沿用已確認的捲動與 GSAP／ScrollTrigger 整合方式，處理 resize、內容更新、清理與減少動態；若已有 RAF 驅動，不再同時啟用另一套 autoRaf／ticker。平台載入就緒時機依正式契約，不用固定延遲或自造事件名稱。
- 這些 vendor 的效果在發布前台後才會生效，畫布沒有套件效果不表示載入失敗；畫布保留可編輯的靜態內容，不為讓畫布動起來自行補 script／link。
- 本機獨立靜態預覽不具備 EVO 發布載入器。優先使用案件已核對的本機預覽環境；預覽專用套件引用不得混入待匯入版型。缺預覽依賴時明列未驗證，不以 data-vendor 代替本機實際載入，也不自行新增 CDN 作補救。

## 發布與驗收

發布測試前台後，檢查套件檔案是否由系統載入、版本與宣告名稱是否正確、console 警告／錯誤、是否重複載入，以及初始化後的實際操作。檢查本案使用的輪播、燈箱、平滑捲動與 GSAP／AOS；沒有使用的套件不新增。交付分開記錄「宣告／工具列開關」「套件載入」「JS 初始化」「發布前台實測」，沒有發布環境或實際站台載入異常時列待驗／待處理，不宣稱已通過。
